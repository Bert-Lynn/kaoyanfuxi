# 研途 · 考研复习工作台

给考研复习使用的可视化计划网站。当前版本部署在 GitHub Pages 子目录：

https://bert-lynn.github.io/kaoyanfuxi/

## 已实现

- 西综 / 英语 / 政治三板块任务管理
- 每日任务新增、编辑、删除、勾选
- 每日模板自动生成任务，并可自定义星期、时长和章节
- 顶部总进度、分科进度、专注时长、考试倒计时
- 一周进度可视化
- 全局任务检索（支持任务名、章节、日期、科目）
- 单任务专注计时
- 三个 B 站冥想休息入口
- 每周固定检查清单
- 每日复盘笔记
- 每日随机/轮换的循证备考提示
- 本地浏览器自动保存
- JSON 数据导出 / 导入备份
- 响应式手机端布局
- 基础 SEO 元信息，可被搜索引擎索引

## 数据说明

这是纯静态网页。复习任务和完成状态保存在浏览器 localStorage，不会提交到 GitHub，也不会公开。

如果以后需要手机、电脑实时同步，可以再接 Supabase / Firebase 等后端，并加登录。
