# 研途 · Study Desk

独立考研复习工作台。只在 `Bert-Lynn/kaoyanfuxi` 开发，通过 GitHub Actions 发布到：

https://bert-lynn.github.io/kaoyanfuxi/

## 4.0 功能

- 西综、英语、政治每日计划、独立完成状态、自由增删改、章节备注、日期导航与检索。
- 保留四日真题轮转、上午西综 150 分钟、下午英语、葫芦丝与生化任务。计划推进不伪装成实际完成；累计阶段进度依据初始基线及已勾选任务。
- 连续随机练题：单选/多选、解析、下一题、自动续题开关、错题重练、今日及累计作答次数、正确率和去重题数。题池用完后进入新一轮，不伪称无限不同题目。
- 初始题库 20 题：1 道真题公开整理版 + 3 道真题考点改写 + 16 道原创练习；**不把改写题或原创题冒充原卷真题**。每题区分来源级别。整理版为已对照 233 网校页面的 2019 年西综第 3 题，不是官方扫描件或官方答案。支持有使用权限的真题 JSON 导入，要求年份、题号、来源；导入仅存当前账号/本机，不提交公开 GitHub。
- 2022、2024、2026 英语模拟卷默认保护；练题与搜索均不泄露其导入题目，可在设置中明确解除保护。
- 自由计时：小时/分钟/秒、倒计时或正计时、任务关联、暂停继续、后台时间戳校准、结束记录、跨午夜分日统计。自定义本次时间不改写任务计划时长。运行中的计时器只在当前标签页保存；结束后的记录可同步。
- 登录与 Supabase 同步接口：独立账号空间、逐记录版本检查、冲突人工选择、离线保留、显式导入访客数据。
- 新版响应式界面、三科识别色、任务与练题独立视图、休息视频入口、JSON 备份。

## 云端状态：需要项目配置

源码默认 `config.js` 为空，表示**尚未接通数据库**；页面会明确显示仅本机保存，登录不可用。不是仅加登录框就宣称已同步。

连接一个授权的 Supabase 项目，执行 `supabase/schema.sql`，完成 Auth/邮件设置，并配置 Actions 仓库变量 `SUPABASE_URL` 和 `SUPABASE_PUBLISHABLE_KEY` 后重新运行部署。完整步骤见 [supabase/SETUP.md](supabase/SETUP.md)。

只允许公开 publishable / anon key。**禁止上传数据库密码、service_role、secret key 或账号密码。**数据库使用 RLS，以 `auth.uid()` 隔离记录。前端不保存明文密码；SDK 管理登录会话令牌。

上线前仍需用真实项目测试：邮箱验证、两台设备登录与同步、不同用户隔离、断网重连和冲突处理。当前本地测试不能替代这些云端验收。

## 数据兼容

初次访客访问尝试迁移 `kaoyan-v3`、`kaoyan-v2`、`yantu_kaoyan_v1` 旧版浏览器记录；保留原始键与备份。新账号不会静默接管访客数据，需明确点击导入。换设备前优先导出备份，或确认云端状态已显示同步完成。

## 测试与部署

```bash
node --test tests/core.test.mjs
node scripts/build.mjs
```

测试覆盖规划、迁移、计时、随机题、判分、模拟卷保护、账号空间和版本冲突。界面另经离线 Chromium 交互检查；没有将测试存储替身冒充实际云端测试。

工作流只发布 `_site/` 中的白名单静态文件，不发布 SQL、测试或备份。页面元信息允许搜索引擎收录，不保证搜索引擎立即收录。
